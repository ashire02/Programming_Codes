# Programming_Codes

A collection of remote sensing, geospatial, and data-science scripts.

## Projects

| Folder | Description | Platform |
|---|---|---|
| [`NDVI_Nepal/`](./NDVI_Nepal/) | NDVI analysis of Nepal using Landsat 5/8/9 Surface Reflectance | Google Earth Engine (JS) |
| [`cmip6-csv-to-netcdf/`](./cmip6-csv-to-netcdf/) | Convert CMIP6 Nepal wide-CSV projections to CF-1.8 gridded NetCDF, with an independent verifier | Python |
| [`eqm_bias_correction/`](./eqm_bias_correction/) | Empirical Quantile Mapping bias correction of CMIP6 point data against DHM observations | Python |
| [`hru_routing_length/`](./hru_routing_length/) | DEM-based D8 overland flow routing length per HRU, plus a DEM quality diagnostic | Python |

Each folder has its own `README.md` with setup, configuration, and usage details.
